# 截图归档说明

本目录用于存放「宠物领养管理系统」课程报告所需的界面截图。
文件名请严格按下表命名（PNG 格式，建议分辨率 1440×900 或 1920×1080，浏览器窗口宽度 ≥ 1440px）。

> 第 11 步联调时已经用 Chromium（1440×900）自动截取了一整套当前实现的界面，
> 可直接使用。若后续修改了界面，请按同样的命名重新截取覆盖，
> 或者直接手工截图替换 —— 下表的「截图要点」就是人工截图时的检查清单。

## 注意事项

1. 截图前请先确认后端（8080）与前端（5173）均已启动，且浏览器已登录对应账号。
2. 涉及个人信息的截图请先在「个人中心」中改好昵称与手机号，便于与测试记录中的实际结果对应。
3. 建议按 01 → 16 的顺序依次截图，便于与 `../测试记录.md` 的用例编号对应。
4. 全部截图完成后可直接引用到课程报告的「系统界面展示」章节。
